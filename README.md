# Әйдә Bistro

Responsive website for the bistro on Ferma-2, 76, Kazan.

Plain HTML, CSS and JavaScript: no build dependencies.

## Features

- Original photography and logo from the bistro's public Telegram channel
- Menu categories and dish information dialogs
- Bonus information, social links and FAQ
- Mobile navigation and reduced-motion support
- Address, hours, telephone and map link

Edit text in `index.html`, presentation in `style.css`, dish details and interactions in `script.js`.

Current prices and inventory are not provided. The site directs guests to the team for current details and does not accept online orders.
